# CFDBench trained checkpoints

This directory contains the author-produced trained checkpoints from the reported CFDBench portability study.

The public checkpoint set is complete for the recovered authoritative run state:

- targets: `dense`, `reduced`;
- learner families: `fno`, `unet`;
- seeds: `0`, `1`, `2`;
- states per run: `FINAL_MODEL.pt` and `RESUME.pt`.

That gives 24 PyTorch checkpoint files in total.

`FINAL_MODEL.pt` is the sealed final model state for the corresponding run. `RESUME.pt` is the preserved resumable training state from the same run lineage. The byte-level SHA-256 and size of every public checkpoint are recorded in `CHECKPOINT_MANIFEST.tsv`.

These checkpoints were generated by this project. They are not third-party pretrained weights.

The public repository intentionally does not redistribute the recovered copied CFDBench U-Net/FNO executable model definitions because the upstream source-redistribution terms were not established during release preparation. See `../SOURCE_AVAILABILITY.md`. The checkpoints are therefore provided as exact author-generated research artifacts and provenance records; loading them for execution requires compatible model definitions obtained or reimplemented under appropriate terms.
